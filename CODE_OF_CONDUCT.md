# Code of conduct

This project is about honest, useful information for security teams. The same standard applies to how we treat each other.

- Be respectful and assume good faith. Disagree with claims, not with people.
- Back up statements about products with sources. Opinions are fine when they are labelled as opinions.
- Disclose affiliations. If you work for, sell, or resell a product, say so in any issue or pull request that touches it or its competitors.
- No harassment, personal attacks, or discriminatory language.
- No marketing. Entries describe what a product does and where it falls short, not why to buy it.

Maintainers may edit, close, or remove contributions that break these rules, and may block repeat offenders. To report a problem privately, use the contact on the maintainer's GitHub profile.

This code of conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
